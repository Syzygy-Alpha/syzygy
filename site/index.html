Essencial

Perguntas importantes.

O SYZYGY já é um produto pronto?

Ainda não. É uma plataforma em construção incremental. Foundation, Forge, Mycelium, Observatory e NERV possuem MVPs locais; capacidades distribuídas avançadas permanecem no roadmap.

O sistema depende de serviços em nuvem?

Não como requisito fundamental. O princípio local-first exige que o núcleo funcione localmente sempre que possível. Serviços externos podem ser extensões substituíveis.

Como os módulos se comunicam?

Por contratos explícitos: APIs, eventos, mensagens, esquemas e protocolos. O acesso direto às implementações internas é evitado para preservar baixo acoplamento.

Qual é a stack atual?

Os módulos funcionais usam principalmente Python, FastAPI e SQLite. Foundation também oferece execução com Docker e um adaptador NATS opcional. O site institucional é estático e não depende dessas tecnologias para funcionar.

Como acompanhar ou contribuir?

O código, os ADRs, o roadmap e os registros de atividade vivem no GitHub. Mudanças seguem Conventional Commits e incrementos significativos são documentados.
